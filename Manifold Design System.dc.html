The Manifold design system

A dark-first operator language for an AI gateway. Layered tokens, a status system built for degradation, and dense data surfaces — codified so engineering and design ship the same product.

Principles

Deny-first, fail-closed

The UI defaults to the safe state. Unknown price blocks a hard budget; a removed entitlement is a tripwire, not a toggle. Destructive intent always shows its blast radius first.

Status is a system

Up · verifying · down · idle is one vocabulary — dot, badge, banner, row accent all derive from it. Amber means unknown, never merely warning. Live things pulse; settled things don't.

Density with clarity

This is an operator tool. Tables are the primary surface; monospace tabular numerals keep columns scannable. Whitespace is earned by hierarchy, not sprinkled.

Two themes, one truth

Every color is a semantic token. Components never name a hue — they name a role. Dark and light are two resolutions of the same table.

Config & publish

Changes stage as a draft and reach the gateway only on publish. The plan is a diff; destructive intent hits a tripwire that must be approved separately. Every revision is content-addressed and reversible.

Tripwire holds 1 destructive change for approval — entitlement removal, research → embed.
